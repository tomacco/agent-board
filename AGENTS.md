# Agent Board: agent notes

- Swift package (`Sources/AgentBoard`), built into an app bundle by `build.sh`; no Xcode project. `install.sh` is idempotent.
- The panel never enforces anything itself. Enforcement is `bin/boardd` plus `hooks/hands-off-guard.sh`; keep it that way so any other control only has to flip the flag.
- Any change to the block list or the hook pattern must pass `tests/test-hands-off.sh`, including the "allows" cases.
- Check layout with `build/AgentBoard.app/Contents/MacOS/AgentBoard --preview` and capture the printed window number. Never click the menu bar to test it: synthetic input while a person may be at the keyboard is not allowed.
- If hands off is on (`bin/boardctl status`), do not speak, play sounds or drive input. Do not turn it off yourself.
